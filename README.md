# Backrooms Survival

A 10-level first-person survival shooter set in the yellow Backrooms, built with Three.js in a single HTML file.

**Play:** https://ansonchan0614-code.github.io/backrooms-survival/

## How to play
- Survive until the timer hits zero.
- **WASD** move · **mouse** look · **click** shoot · **Space** jump
- Headshots kill instantly. HP regenerates after 4 seconds without damage.
- Clear a level to unlock the next. Progress is saved in your browser.

Desktop browser with mouse and keyboard required.
